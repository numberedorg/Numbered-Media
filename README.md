# Jellyfin Plugin: Numbered Media Branding

This plugin overrides Jellyfin's default branding so your server displays as **Numbered Media** everywhere (UI, DLNA, API).

## ✨ Features
- Changes server name from "Jellyfin" → "Numbered Media"
- Applies automatically on startup
- Clean, standalone plugin (no Jellyfin core edits)
